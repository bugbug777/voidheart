這裡是 Void Heart，一個用來留下筆記、文章與專案紀錄的地方。

第一版的目標很單純：讓寫作變得容易，讓閱讀保持安靜，讓網站可以穩定部署到 GitHub Pages。

## 會寫些什麼

- 技術學習與實作紀錄
- 閱讀筆記
- 生活觀察
- 還在形成中的想法

## 寫作方式

文章會以 Markdown 撰寫，並透過 Git 做版本管理。當文章準備發布時，只要把 `draft` 設為 `false`，推送到 GitHub 後就會自動部署。

```yaml
draft: false
```

這個起點很小，但足夠讓內容慢慢長出自己的形狀。
