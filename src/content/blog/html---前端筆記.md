## 什麼是 HTML？

HTML 為 Hyper Text Markup Language 的縮寫，是門標準的網頁標記語言，主要用來架構整個網頁的內容結構，透過各式各樣的元素，最終形塑出整個網頁的架構。

## HTML 元素

元素（element）是 HTML 中最基礎的結構，元素的組成主要分成：

1. 開頭標籤（heading tag）
2. 內容（content）
3. 結尾標籤（ending tag）

包含這些組成，我們就會說這是一個元素。

```html
<!-- 語法 -->
 <tag>content</tag>

<!-- 範例  -->
 <h1>This is heading</h1>
```

在特別的情況下，我們某些元素因為特別的用途，不會包含內容以及結尾標籤，這樣的元素我們稱為**空元素**。

```html
<!-- 空元素範例，圖片 -->
 <img src="image_url" alt="image description">
```

另外，HTML 是支援巢狀的元素結構寫法的，如下所示。

```html
<head>
  <title>這是網頁頁籤的標題</title>
</head>
```

### 常見的元素

#### \<h1\>

`<h1>` 為標題元素，一共有 `<h1>` ~ `<h6>` 六種級距，良好的使用這些標題元素，對於 SEO 有良好的助益，搜尋引擎通常也會透過這樣的結構，將你的文章內容進行分類，一個網頁只能夠使用一個 `<h1>`。

- `<h1>` 頁面標題
- `<h2>` 區塊標題
- `<h3>` 次標題

頁面上的 `<h1>` 是最重要的標題，通常只會有一個，然後依序使用不同級距的標題元素，來將內容進行有結構的拆分。

#### \<p\>

`<p>` 為文字段落，用來顯示想讓使用者看到的內容，瀏覽器會自動將內容中的空白、斷行自動移除，如果有需要將文字內容斷行，可以使用 `<br>`。

#### \<hr\>

`<hr>` 水平線元素，英文為 **h**orizontal **r**ule，如果想要將不同的內容進行主題式的劃分，但是又不想太花俏，使用 `<hr>` 是最簡便的方式。

#### \<pre\>

`<pre>` 不會受到如同 `<p>` 一樣，預設會去除所有空白、斷行的影響，會保留文字段落原始的特性，很適合用來處理，四言、五言絕句律詩的問題。

### Text Formatting

HTML 提供一些元素，這些元素的的預設樣式，可以幫助文字簡易的進行格式化處理，例如：粗體、斜體、刪除線、上標、下標 ⋯⋯，而這些樣式都可以透過 CSS 處理，在不考慮語意化的情況下，現行主要都透過 CSS 來處理類似的樣式。

#### \<b\> & \<strong\>

- \<b\> 表示 bold text
- \<strong\> 表示重要的文字

#### \<i\> & \<em\>

- \<i\> 表示 italic 斜體
- \<em\> 表示 emphasized 強調

#### \<small\>

用來處理次標題，或者相對不那麼重要的時間、日期之類的文字。

#### \<mark\>

用來標記重要的文字，使用此元素的好處是，語意化的強化，

#### \<del\>

刪除線，以我自己的經驗來說，這個使用情境相對少，並且相同的樣式可以透過 CSS 來進行復刻。

#### \<ins\>

insert，插入，樣式為替文字加上下底線，可以使用 CSS 達到相同的樣式。

#### \<sub\> & \<sup\>

上標以及下標，在標記數量的時候會使用到，通常會搭配 CSS。下標也可以用來在化學分子式的標註。

### Quotations

#### \<q\> & \<blockquote\>

兩個差異在於 `<q>` 用於較簡短的引用，通常會是行內的，而 `<blockquote>` 則是用於較長的引用，通常會分段。

```html
<!-- blockquote -->
 <p>這是 Void Heart 的引言：</p>
 <blockquote cite="https://voudheart.cc/">
 心投虛谷，<br />
 眼望長空。<br />
 浮生若夢，<br />
 萬事皆空。
 </blockquote>

<!-- q -->
 <p>Void Heart 的目標：<q>排解空洞的心靈。</q></p>
```

#### \<abbr\>

`<abbr>`，表 abbreviation，用於縮略字、縮寫。例如：HTML 為 Hyper Text Markup Language 的縮寫。

```html
<p><abbr title="Hyper Text Markup Language">HTML</abbr> 是標準的網頁基礎語言之一。</p>
```

#### \<address\>

用來顯示聯絡地址，或者相關的聯絡資訊。

#### \<cite\>

與屬性的 `cite` 不同，`<cite>` 主要用在作品的名稱，會以斜體顯示。作品可以是：書籍、畫作、電影、雕塑 ⋯⋯。

```html
<!-- 孟克的吶喊 -->
 <img src="孟克的吶喊.jpg"  alt="孟克的吶喊">
 <p><cite>孟克的吶喊</cite> by Edvard Munch. Painted in 1893.</p>
```

#### \<bdo\>

`<bdo>` 表示 Bi-Directional Override，也就是雙向覆蓋的意思，不論中文還是英文，我們都是由左而右書寫，但是某些文字是由右而左，例如：阿拉伯文，這時候會需要使用這樣的元素。

```html
<bdo dir="rtl">這一行文字，會由右而左的顯示。</bdo>
```

## HTML 屬性

網頁元素可以幫助我們架構出網頁的各類結構，比如我想要一個標題，我會使用 `<h1>` 這個標籤元素，想要圖片就使用 `<img>`，想將網頁連結到其他地方就使用 `<a>`。

但是單純的使用元素的標記，只能讓我們知道，這個網頁的這個部分要呈現的是怎樣的內容，無法讓這個元素本身知道要呈現怎樣的內容，屬性可以替這個元素提供額外的資訊。

用文字說明可能不太容易理解，但是簡單的來說，今天我如果要讓一段文字可以連結到其他網頁，我總需要讓這段文字知道要連結到哪裡的網址吧？

而 HTML 屬性，就是用來補強這一部分的語法，同樣的元素可以有不同的表達方式，也就是擁有不同的屬性。

```html
<!-- 第一張圖片 -->
 <img src="picture_1.png" alt="picture 1" >

<!-- 第二張圖片 -->
 <img src="picture_2.png" alt="picture 2" >

<!-- 連到 Google 的連結 -->
 <a href="https://www.google.com/" >Google</a>

<!-- 連到 Yahoo 的連結 -->
 <a href="https://www.yahoo.com.tw/" >Yahoo</a>
```

參考上面的範例，我們有兩個 `<img>` 以及 `<a>` 元素，但是兩個圖片分別會顯示出不同的圖片，原因在於，我們給予不同的屬性值，而 `src` 就是 `<img>` 這個元素的屬性，在 `<a>` 元素也是同樣的道理，`href` 就是 `<a>` 的屬性。

不同的元素會有不同的屬性，這些屬性是用來強化對元素的描述，進而呈現不同的內容，可以是展示不同的圖片，可以是連結到不同的網站。

不同的元素，通常會有不一樣的屬性，但是有些屬性是共用的，例如 `title` 這個屬性就可以同時作用在 `<img>` 以及 `<a>` 上面。

### 常見的屬性

#### lang

`lang` 通常作為 `<html>` 這個根元素的屬性，主要用來幫助搜尋引擎以及瀏覽器識別這網頁的主要使用的語言，這會有助於 SEO，以及瀏覽器一些預設設定的調整。舉例來說，你在使用中文搜尋資料的時候，幾乎不會出現英文的資料，這是由於搜尋引擎的演算法，已經將龐大的資料進行處理、過濾，而一部分的根據，就是這個小小的屬性。

#### style

`style` 可以讓我們直接在開頭標籤撰寫元素的樣式，由於 CSS 這個語言的出現，現在比較少人會透過這種方式撰寫樣式，但是使用 `style` 屬性撰寫的樣式，會有較高的樣式權重，這意味著你的有些樣式可能會被這樣形式的語法給覆蓋了，使用上需要謹慎。

#### src

`src` 通常與 `<img>` 搭配使用，讓瀏覽器知道要從哪個 source 找到圖片資源。

#### alt

`alt` 通常與 `<img>` 搭配使用，在某些情況下，網路中斷或者網速較慢的時候，`alt` 中的文字描述依然會顯示給使用者，通常用來描述圖片的狀況。

#### title

`title` 作為一個屬性使用，主要用來提示使用者這個元素是幹嘛用的，使用方式為，當使用者把滑鼠停留在該元素上面時，`title` 中的文字就會顯示給使用者觀看，可以起到提示的作用，或者加強內容的描述。

#### href

`href` 與 `<a>` 搭配使用，用來錨定連結的位置，可以連結到外部的網站頁面，也可以作為網頁內部的連結使用，內部連結的使用，概念上會類似捷徑的感覺，可以連結到不同的段落標題。

## 撰寫 HTML 的注意事項

1. HTML is not Case Sensitive。 意思是 HTML 不區分英文字母大小寫，有些程式語言在撰寫變數時是會區分字母大小寫的，大寫、小寫組合而成的名稱，會代表不同的東西。
2. 不要忘記結尾標籤。 HTML 是個鬆散的語言，即使你沒有加上結尾標籤，瀏覽器還是可以正常顯示，但是這會導致發生 bug 的時候，你會找不到問題的原因，所以你應該保持良好的習慣，好好使用結尾標籤，將每個元素都確實關上。
