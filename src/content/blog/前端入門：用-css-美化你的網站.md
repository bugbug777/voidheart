## 什麼是 CSS？

CSS（ **C**ascading **S**tyle **S**heets ），階層式樣式表，簡單的來說就是一種可以用來裝飾網頁的電腦語言，沒錯，跟你想的一樣，它也不是程式語言。

樣式的概念很好理解，就跟你衣服的穿搭一樣，今天心情如何、天氣如何，想要穿什麼樣的服裝，你可以隨心所欲的搭配出自己想要的樣式，只要你想得到，沒有你做不到。

階層可以雖然可以簡單的用圖層的概念去理解，但是會有些微的不同，透過不同的圖層一層一層堆疊出想要的效果，通常不會有問題，但是在 CSS 中，更多時候層遞的概念取決於語法賦予元素的權重。

即便在 HTML 的結構中，元素是層層包裹的巢狀結構，假設最內層的元素，總是會在最層元素的上層，但是透過 CSS 語法的操縱，內層也可以是最下層，反之亦然，這邊描述的比較抽象，不過也是因為這樣的特性，給了我們更多的彈性，來進一步優化我們的網頁。

## CSS 語法

CSS 的語法通常透過選擇器（ selector ）以及不同的規則組合成，所這樣的一組的規則也會稱為 rule set。

```css
p { color: red; }
```

參考上面的語法範例，p 是我們的選擇器，透過指定選擇器到對應的元素，以此處的語法來說，表示我們的使用選擇器選取 HTML 中所有的 `p` 元素。

`color: red;` 的部分，我們稱這個為一個宣告（ declaration ）或稱規則，在大括號中，我們可以不只撰寫一組規則，可以有很多規則，用來描述一個元素應該怎麼展示在網頁上。

`color` 表示的是選取到元素的性質（property），`red`則表示這個性質的值是什麼，以 `color` 舉例，我們可以給 `p` 這個元素不同的值，可以是 `yellow`、`blue`、`green` ⋯⋯ 等等不同類型顏色的值，不同的元素性質會有不同的值可以使用，如果今天要調整的性質是 `width`，也就是元素的寬，我們的值可能就會是 `100px`，這樣具有尺寸概念的值。

## 盒模型（ Box Model ）

CSS 有一部分是用來裝飾我們的網頁，也就是比較直覺的 font-size、color、border ⋯⋯ 等等，但是也有一部分是用來調整網頁的佈局，也就是我們所謂的排版，這個時候盒模型的概念就非常重要。

元素可以簡單分成區塊元素（block）跟行內元素（inline），如果你有看過我上一篇文章，[用 HTML 創建你的第一個網頁](./前端入門：用-html-創建你的第一個網頁.md)，最下方的參考連結，並且有略略的看完，你應該會發現，有些元素預設就會把整個版面佔滿，也就是寬度預設就會佔滿整個視窗，所以當你使用下一個元素的時候，內容會出現在下一行，這個就是區塊元素，反之，行內元素不會有換行的行為。

我們在打造網站的時候，通常不會希望網站是一欄式的瀏覽，這也不符合實際的需求，通常會有側欄，以及主要的內容區塊，所以可能會是兩欄式、三欄式的排版方式。

這時候要控制每個欄位的寬度，就會需要考慮到盒模型。

正常情況下，你會很直覺的知道，要控制元素的寬度，就要使用 `width` 這個 property，假設今天要開一個版型是 1000px 的網頁，側欄如果佔 200px，你會很直覺計算出主要區塊應該要是 800px，但是這實際上會發生問題。

我們的版面限制在 1000px，不論有多少個元素在其中排列，只要加起來超過 1000px，超過的元素就會被排到下一列，所以如果不考慮盒模型的情況下，800px + 200px 就會剛好是 1000px，恰好符合我們的需求，不會發生元素被排擠到下一行的狀況。

但是如果將盒模型考慮進來，上面的情況實際上有可能不會發生，因為有些元素本身會有預設的樣式，`border`、`margin`、`padding` 這些 property 都會影響尺寸，如果原本 `width` 為 200px，但是加上 `border` 以及 `padding` 結果寬度變成 226px，這就會導致整體的寬度超出 1000px，擠壓到最後的元素，進而導致元素被推擠到下一行。

上面講解的比較繁瑣，但是其實和模型的概念很簡單，`width` 這個 property 實際上指涉的是元素內容（ content ）部分的寬度，如果今天要討論和模型的高度的話，`height` 這個 property 就會是內容的高度。

所以在尺寸的實際計算上就會一次把這些 properties 考慮進來，以寬度來舉例，`實際的寬度 = left margin + left border + left padding + width + right padding + right border + right margin`。

最後，再不調整情況上，上述就是元素在預設樣式下盒模型的計算方式，但是因為計算上不太方便，所以實務上，我們通常會透過 `box-sizing` 這個 property 進行修正，這邊就賣個關子，讓你自己去研究了。
